# كاشير الحجي (alhjexx)

نظام كاشير لمطعم الحجي على تابلت Android بالوضع الأفقي، باللغة العربية واتجاه RTL، ويعمل بالكامل دون إنترنت.

- **أنواع الطلبات:** داخل المطعم، وسفري فقط. لا توجد أي وظائف توصيل (دلفري).
- **التقنية:** Java + XML Views، دون Compose، ودون أي مكتبة خارجية في التطبيق (Android SDK و SQLite فقط).
- **الحزمة:** `iq.haji.alhjexx` | minSdk 26 | targetSdk / compileSdk 35 (Android 15).
- **الطابعة:** Bluetooth حرارية 58mm بأوامر ESC/POS نقطية (صورة)، حتى يظهر النص العربي متصلاً على الطابعات التي لا تدعم العربية.

## البناء

يُبنى التطبيق تلقائياً على GitHub Actions عند كل رفع (`.github/workflows/build.yml`):

1. اختبارات الوحدة واختبارات القبول (`./gradlew testDebugUnitTest`).
2. بناء `app-debug.apk` (`./gradlew assembleDebug`).
3. رفع الـ APK كـ Artifact باسم `alhjexx-debug-apk`.

محلياً: `./gradlew assembleDebug` مع Android SDK 35 و JDK 17.

## التعريفات المحاسبية

- **إجمالي المبيعات** = مجموع أسطر الطلبات غير الملغاة قبل الخصم.
- **صافي المبيعات** = إجمالي المبيعات − الخصومات.
- **الطلبات الملغاة** تبقى في قاعدة البيانات بقيمتها الأصلية، وتُعرض منفصلة ولا تدخل في المبيعات.
- **الاسترجاع** يُسجَّل فقط إذا أُعيد المال فعلاً، فالإلغاء لا يعني دائماً إرجاع المبلغ.
- **المصروفات** تُعرض منفصلة ولا تُخصم من المبيعات.
- **النقدية المتوقعة** = الافتتاحية + النقد المقبوض − الاسترجاع النقدي − المصروفات النقدية + الإيداعات − السحوبات.

## السياسات

- وردية مفتوحة واحدة على الجهاز في أي وقت.
- كل طلب مرتبط برقم الوردية التي اعتُمد فيها.
- إلغاء الطلب مسموح لطلبات الوردية المفتوحة فقط، بسبب إلزامي وموافقة مدير، حتى لا تتغير أرقام ورديات مغلقة.
- الوردية المغلقة تُحفظ نتائجها نهائياً، وإعادة فتحها إجراء إداري يُسجَّل مع سببه ونتائج الإغلاق السابقة.
- تعديل سعر صنف لا يغير الفواتير السابقة، لأن كل سطر طلب يحفظ الاسم والسعر وقت البيع.
- الصنف أو القسم المستخدم في طلبات سابقة يُؤرشف ولا يُحذف نهائياً.
- رقم الفاتورة بصيغة `yyMMdd-NNNN` فريد بقيد في قاعدة البيانات، ولكل طلب أيضاً معرف UUID فريد يمنع الاعتماد المكرر.

## ما يحتاج اختباراً على الجهاز الفعلي

اختبارات القبول تعمل على قاعدة بيانات SQLite حقيقية عبر Robolectric في GitHub Actions. لكن الأمور التالية لا يمكن التحقق منها إلا على التابلت والطابعة:

- الاتصال بالطابعة الحرارية، ووضوح الطباعة والمحاذاة العربية. استخدم «الإعدادات ← اختبار الطباعة».
- شكل الواجهات وسهولة اللمس على شاشة التابلت.
- اختيار ملف النسخة الاحتياطية وحفظه عبر نافذة النظام.
